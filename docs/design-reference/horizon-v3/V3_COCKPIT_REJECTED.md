# Horizon Cockpit V3 — rejected visual exploration

Status: **REJECTED / SUPERSEDED — NO PRODUCTION VISUAL AUTHORITY**
Decision date: 2026-08-18

The user explicitly rejected Horizon V3 as prototype-looking and below the
quality of the approved portrait Nembra Home direction. The PNGs and original
handoff in this directory are retained unchanged as historical design evidence
only.

Do not implement, copy, merge, or revive V3's styling, layout geometry, map
art, typography, road rendering, metric arrangement, launcher, or visual
components. Do not rasterize these images into the shipped app and do not use
them as screenshot acceptance targets.

Only nonvisual production foundations developed during this exploration remain
valid: landscape scene/orientation authority, truthful data-state contracts,
automatic ride and durable local-day ledgers, versioned road-exploration and
MapKit adapter boundaries, accessibility semantics, performance budgets, and
QA evidence requirements. A later user-approved cockpit target will define the
production composition.
