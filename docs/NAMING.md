# Product naming phase

Date: 2026-08-04

This is a preliminary product-conflict sweep, not legal trademark clearance.

## Candidates reviewed
1. Nembra — quiet, technical, premium; flexible beyond scooters.
2. Ternyx — sharper/technical, but more hardware/gaming-coded.
3. Rovyn — calm movement/roaming association.
4. Arclane — navigation/road association.
5. Rovea — movement/travel association.
6. Veyra — premium abstract name.
7. Velora — velocity/mobility association.
8. Movana — mobility-forward.
9. Veylan — precise/technical.
10. Orvane — premium neutral abstract.

## Conflict sweep outcome
- Veyra: existing App Store/software usage -> reject.
- Velora: multiple current apps and mobility branding -> reject.
- Movana: existing moving/mobility software/services -> reject.
- Arclane: existing software companies/apps and multiple GitHub repos -> reject.
- Rovea: existing travel platform -> reject.
- Veylan: existing app/software trademark usage -> reject.
- Orvane: existing software/app usage -> reject.
- Rovyn: active software/company/developer usage -> reject.
- Ternyx: exact GitHub project usage exists; no strong mobility tie found, but the collision plus tone makes it weaker -> reject.
- Nembra: searches primarily resolve to the place/community name Nembra in Asturias; no obvious current scooter/mobility app or major software brand surfaced in the initial sweep. GitHub search returned only partial-name repositories, not a prominent exact-match platform in the sampled results.

## Shortlist
### Nembra — selected
Personality: quiet precision, advanced mobility, neutral enough for multiple OEMs. Looks credible as “Nembra” on an App Store page and as a landscape instrument brand.

### Ternyx
Personality: more technical and aggressive. Rejected because it leans too hardware/gamer and has an exact GitHub collision.

### Rovyn
Personality: friendly premium movement. Rejected because current software/company/developer usage is too broad.

## Decision
Proceed as **Nembra** for development. Schedule a formal trademark/domain/social clearance before release branding becomes expensive to change.
