## Before running

- Use the Mac that has Xcode 27 and your Apple signing account.
- Connect and unlock the intended iPhone by USB, trust the Mac, and enable Developer Mode.
- Keep the scooter out of the procedure until the build is installed and the app shows the dedicated private Research provenance path.

## Run

From an existing Nembra clone:

```bash
git fetch --all --prune
git switch -C field/capture-now-gpt56 origin/field/capture-now-gpt56
bash scripts/field/es80_capture_now.command
```

The helper then:

1. selects Xcode 27 and requires the iOS 27 Simulator runtime;
2. selects the connected physical iPhone;
3. detects the Apple Development Team ID when possible (otherwise asks once);
4. creates a detached exact-source worktree at the frozen Capture SHA;
5. runs the real Capture Xcode 27 Simulator acceptance locally, bypassing the GitHub `xcode-27` preview queue;
6. invokes the frozen candidate's existing TODAY Research-only signed-field producer;
7. independently retains the signed IPA/evidence generated by that producer;
8. installs that exact retained build on the selected iPhone without rebuilding it;
9. writes a private local install receipt into the retained candidate folder on the Desktop.

It deliberately does **not** launch the app or start Bluetooth automatically.
